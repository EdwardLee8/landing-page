**主營業務**

依公司公開分類慣例，集團核心業務涵蓋三大板塊：

1. **電信服務**：國際語音、漫遊批發、移動虛擬網絡（MVNO）、國際短信等跨境電信業務
2. **互聯網服務**：互聯網接入、數據中心、雲服務

**淨有息負債（推算）**

= 短期貸款 + 長期貸款 + 融資租賃負債合計 − 現金及等價物

- FY2025：(1,089,283,320 + 1,852,504,220 + 270,966,000) − 1,756,762,900 = **1,455,990,640 人民幣**
- FY2024：(3,297,628,440 + 320,409,840 + 300,036,960) − 1,491,850,440 = **2,426,224,800 人民幣**（推算）

淨有息負債／股東權益：

- FY2025：1,455,990,640 / 9,956,194,060 = **14.62%**（推算）
- FY2024：2,426,224,800 / 9,924,370,680 = **24.45%**（推算）

觀察：FY2025 集團大幅優化資本結構，將短期貸款置換為長期貸款，淨有息負債率下降約 9.83 個百分點，融資壓力顯著緩解。

### 6.2 ROE 杜邦分解（FY2025，本地港股周期性財務數據庫推算）

| 指標 | 公式 | FY2025 | FY2024（期末口徑）|
| --- | --- | ---: | ---: |

| 權益乘率 | 平均總資產 / 平均股東權益 | 1.585 倍 | — |

- 平均總資產 = (FY2025 + FY2024) / 2 = (15,342,998,140 + 16,164,028,200) / 2 = 15,753,513,170

- FY2025 ROE 4.13% 較 FY2024 期末 4.31% 略降，主因淨利率下降（9.71% → 9.64%）及權益乘率提升被總資產周轉率下降所抵消
