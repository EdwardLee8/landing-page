# Oracle Corporation（ORCL）研究報告
**日期：2026年6月9日 | 市場：NYSE | 季度：Q3 2026 (3月10日電話會議)**

---

## Executive Summary

Oracle 公布 Q3 FY2026 業績（2026 年 3 月 10 日）：總收入 $171.9 億，按年增長 21.7%，超預期 $2.8 億；EPS $1.79，超預期 $0.10。Cloud 收入 +25% YoI，OCI（Oracle Cloud Infrastructure）持續加速。

2026 年 5 月重大新聞：（1）Oracle 推出 OCI GoldenGate on Oracle Database@Google Cloud，跨雲數據複製；（2）Oracle Database 內建企業級 MCP Servers，支援 Agentic AI 訪問；（3）Oracle Multicloud 業務持續擴張，與 Microsoft Azure、Google Cloud 深度整合；（4）Cerner 醫療業務改善。

**核心邏輯：OCI + Database + Multicloud + AI 應用。Oracle 是企業數據 + AI 基礎設施的關鍵供應商。** 中線強烈看好。

---

## 一、公司背景

Oracle 為全球最大企業軟件公司之一，業務涵蓋 Oracle Cloud Infrastructure（OCI）、Oracle Database、Oracle Applications（ERP、HRM、CX）、Cerner 醫療。創辦人兼 CTO Larry Ellison 是 Tesla 早期投資人。

## 三、未來六個月利好因素

### 催化劑 1：OCI 持續加速
**為何重要：** OCI 是 Oracle 最快增長業務，毛利率持續改善。

### 催化劑 2：Multicloud 業務
**事件：** 5 月 OCI GoldenGate on Oracle Database@Google Cloud 推出。
**為何重要：** Oracle Database 透過其他 hyperscaler 部署。
**對估值/股價影響：** Database 收入加速。

### 催化劑 3：Agentic AI 接入
**事件：** 5 月 Oracle 推出企業級 MCP Servers。
**為何重要：** AI Agent 直接訪問 Oracle Database。
**對估值/股價影響：** AI 時代企業數據平台首選。

### 催化劑 4：Cerner 改善
**為何重要：** Cerner 業務持續改善。

### 催化劑 5：Fusion + NetSuite 應用
**為何重要：** 應用業務持續穩定。

## 四、主要風險

### 風險 1：OCI 競爭
**傳導路徑：** AWS、Azure、Google Cloud 持續搶佔 OCI 份額。

### 風險 2：AI 投資週期見頂
**傳導路徑：** 客戶 capex 削減 → OCI 訂單減少。

### 風險 3：Larry Ellison 注意力
**事件：** Larry Ellison 同時管理 Oracle、Tesla 投資、xAI 投資。
**傳導路徑：** 治理風險。

### 風險 4：估值已高
**事件：** ORCL P/E 30x+ 創歷史高位。
**傳導路徑：** 任何失望觸發估值收縮。

### 風險 5：雲端轉型速度
**傳導路徑：** 傳統 on-premise 業務下滑快於 cloud 增長。

**中線：** 強烈看好。OCI + Multicloud + Database + AI 四引擎。

**適合投資者類型：** 企業 AI 基礎設施配置首選。
